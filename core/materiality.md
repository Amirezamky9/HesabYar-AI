# اهمیت (Materiality)

> مرجع: استاندارد حسابداری ۱، بند ۷ و مفاهیم نظری گزارشگری مالی ایران

## 📌 تعریف

**اهمیت:** عدم ارائه یا ارائه نادرست اقلام در صورتی بااهمیت است که بتواند به تنهایی یا در مجموع، بر تصمیمات اقتصادی استفاده‌کنندگان که بر اساس صورت‌های مالی اتخاذ می‌شود، تأثیر بگذارد.

اهمیت به **اندازه** و **ماهیت** عدم ارائه یا ارائه نادرست بستگی دارد که با توجه به شرایط محیطی در مورد آن قضاوت می‌شود.

## 📌 عوامل تعیین‌کننده اهمیت

### ۱. اندازه (کمیت)
مبلغ قلم نسبت به مبالغ مرجع (سود، دارایی، درآمد، ...)

### ۲. ماهیت (کیفیت)
- معاملات با اشخاص وابسته
- معاملات غیرعادی
- تغییرات در رویه‌های حسابداری
- خطاها و تقلب‌ها

### ۳. ترکیب اندازه و ماهیت
ممکن است قلمی کوچک از نظر اندازه، ولی بااهمیت از نظر ماهیت باشد (یا برعکس).

## 📌 آستانه‌های پیشنهادی برای نرم‌افزار

| سطح | درصد | مبنا |
|------|------|------|
| بااهمیت | > ۵٪ | سود قبل از مالیات |
| بااهمیت | > ۱٪ | کل دارایی‌ها |
| بااهمیت | > ۰.۵٪ | درآمد عملیاتی |
| بااهمیت | > ۲٪ | حقوق مالکانه |

**⚠️ توجه:** این آستانه‌ها **راهنما** هستند، نه جایگزین قضاوت حرفه‌ای.

## 📌 قواعد نرم‌افزاری

### ۱. ارائه اقلام
- اقلام بااهمیت **نباید تجمیع** شوند
- اقلام بی‌اهمیت **می‌توانند تجمیع** شوند
- هر طبقه بااهمیت از اقلام مشابه **جداگانه** ارائه شود (بند ۲۷ استاندارد ۱)

### ۲. تهاتر
- تهاتر فقط در موارد مجاز استانداردها
- تهاتر اقلام بااهمیت ممنوع

### ۳. افشا
- افشای اطلاعات الزامی **فقط در صورت بااهمیت بودن**
- در مورد عدم افشا: قضاوت حرفه‌ای

## 📌 مثال‌های عملی

### مثال ۱: خرید یک خودرو
- مبلغ: ۵ میلیارد ریال
- کل دارایی: ۵۰ میلیارد ریال
- **نتیجه:** ۱۰٪ از کل دارایی → بااهمیت → ارائه جداگانه

### مثال ۲: هزینه پذیرایی
- مبلغ: ۱۰ میلیون ریال
- کل هزینه‌ها: ۱۰ میلیارد ریال
- **نتیجه:** ۰.۱٪ → بی‌اهمیت → تجمیع در سایر هزینه‌ها

### مثال ۳: معامله با مدیرعامل
- مبلغ: ۵۰۰ میلیون ریال
- کل درآمد: ۱۰۰ میلیارد ریال
- **نتیجه:** ۰.۵٪ → ولی به دلیل **ماهیت** (شخص وابسته) → بااهمیت → افشای جداگانه

def is_material(amount, base_amount, nature_matters=False, threshold=0.05):
    """
    بررسی بااهمیت بودن
    
    Args:
        amount: مبلغ قلم
        base_amount: مبلغ مرجع (سود، دارایی، ...)
        nature_matters: آیا ماهیت قلم بااهمیت است؟
        threshold: آستانه (پیش‌فرض ۵٪)
    
    Returns:
        bool: آیا بااهمیت است؟
    """
    if nature_matters:
        return True
    
    if base_amount == 0:
        return amount != 0
    
    ratio = abs(amount) / abs(base_amount)
    return ratio >= threshold


def classify_materiality(amount, base_amount):
    """طبقه‌بندی سطح اهمیت"""
    if base_amount == 0:
        return "unknown"
    
    ratio = abs(amount) / abs(base_amount)
    
    if ratio >= 0.10:
        return "high"       # بااهمیت بالا - ارائه جداگانه
    elif ratio >= 0.05:
        return "medium"     # بااهمیت - ارائه جداگانه
    elif ratio >= 0.01:
        return "low"        # نسبتاً بی‌اهمیت - می‌تواند تجمیع شود
    else:
        return "immaterial" # بی‌اهمیت - تجمیع شود

# مثال: بررسی اقلام ترازنامه
def group_balance_sheet_items(items, total_assets):
    """گروه‌بندی اقلام ترازنامه بر اساس اهمیت"""
    material = []
    immaterial = []
    
    for item in items:
        if is_material(item['amount'], total_assets, 
                       nature_matters=item.get('related_party', False)):
            material.append(item)
        else:
            immaterial.append(item)
    
    return {
        'material': material,
        'immaterial': immaterial,
        'aggregated': sum(i['amount'] for i in immaterial)
    }
