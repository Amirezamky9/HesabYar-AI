- Tests run against SUPABASE (the dev env switched after Phase 3):
  source `~/workspace/projects/hesabyar-reference/.env.supabase`
  (`HESABYAR_DATABASE_URL` + `HESABYAR_TRYTON__BASE_URL=http://localhost:8010`)
  before any pytest/FastAPI run. Trytond :8010 serves the Supabase
  Tryton DB; start it with `start-trytond-supabase.sh` (password from

- SERIALIZE pytest: never run two pytest processes concurrently — they
  deadlock on the shared HesabYar test DB. The coordinator must sequence
  verification runs across stories.
- No production Moadian connectivity in this phase — simulator only.
  Human approval is a recorded step before any (future) production
  submission. No LLM-initiated submission, ever (spec §19 rule 11).
- No hard-coded tax rates: all annual parameters live in the versioned
  registry. 1405 candidates are seeded CORROBORATED_CURRENT and
  production-BLOCKED until the official source is pinned.
- Standard 15 (Investments) is BLOCKED_SOURCE_GAP for periods beginning
  1405/01/01+ (bundled text is the pre-1404 revision). Standard 43
  (Revenue, from 1404/01/01) and Standard 44 (Leases, from 1405/01/01)
  are VERIFIED_TEXT. See docs/CURRENT_RULES_1405.md.
- Validation outcomes are exactly PASS / FAIL / NOT_APPLICABLE / ERROR;
  ERROR never becomes PASS (fail-closed, per the existing DSL).
- Persian-only, Rial-only product (standing). VibeFarsi/FarsiUI via the
  existing facade for US-405. BFF auth pattern for new dashboard pages.
  No fake data anywhere — gated/blocked items show their reason.
- US-403 closes the get_report gap for TRIAL BALANCE ONLY (posted-moves
  read via REST). P&L, balance sheet and cash flow stay deferred.
